Detalles del refinamiento (C actual vs C refinada)

  • Hero compacto — "A Dictionary of Color Combinations" en Noto Serif JP + "Sanzo Wada · 159 colors" + línea dorada (#c4a265). Sin japonés para no confundir idioma.
  • Featured combination — Una combinación Wada real con PaletteStrip mini + nombre + "Explore →" en dorado. Muestra el destino de la app antes de explorar. Podría rotar diariamente o ser fija.
  • Fondo cálido — Gradiente radial de papel japonés (#f5efe6 → #f0ece4 → #ebe5da) consistente con el OutfitVisualizer. Incluso la tab bar se integra.
  • Swatches con más presencia — border-radius: 10px (vs 6px actual), gap: 10px (vs 4px), inner shadow sutil para profundidad. Se sienten como pastillas de color, no como píxeles.
  • Nombres bajo cada color — 8px en gris sutil (#7a7a7a). No gritan, pero están ahí. "Cherry Blossom", "Evergreen", "Crimson" — dan alma sin robar espacio. Truncados con ellipsis si son largos.
  • Tabs con blur al scroll — Se quedan sticky con backdrop-filter: blur(8px) cuando el hero desaparece. El grid sigue siendo rápido de recorrer.
  • 4 columnas — Compromiso perfecto: 12 colores above-the-fold (vs ~8 en 3-col, vs ~20 en 5-col). Suficiente para browsear rápido sin sentirse abrumado.
  • Combinations screen — Se muestra el flujo completo: tap en color → header con nombre JP + count → PaletteStrips con combinaciones. El fondo cálido se mantiene.

Lo que NO cambia

  • La navegación: tap color → Combinations → OutfitVisualizer (misma estructura)
  • FlatList con 4 columnas (solo cambia de 5 a 4)
  • SwatchGroupTabs (mismo filtrado, mismo comportamiento)
  • Haptics, accessibility, animations (todo preservado)
  • El dato: mismos 159 colores, mismas combinaciones
